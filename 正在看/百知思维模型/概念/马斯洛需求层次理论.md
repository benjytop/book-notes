# 马斯洛需求层次理论

## 简介

**马斯洛需求层次理论** 是心理学家亚伯拉罕·马斯洛 1943 年提出. 人有 5 个层次需求: 生理 / 安全 / 社交 / 尊重 / 自我实现. 第 1 部分首章.

## 5 层需求

1. **生理需求** - 食物, 水, 睡眠
2. **安全需求** - 稳定, 安全
3. **社交需求** - 爱, 归属
4. **尊重需求** - 认可, 地位
5. **自我实现** - 潜能发挥

## 应用

- 用于管理: 满足不同员工需求
- 用于营销: 针对不同需求层次
- 用于自我认知: 我现在在哪一层
