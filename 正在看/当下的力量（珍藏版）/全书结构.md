# 全书结构

## 5 大阶段

- **觉醒** (1-3): 你不等于大脑 → 摆脱痛苦 → 进入当下
- **逃避** (4): 思维如何逃避当下
- **临在** (5-7): 临在状态 → 内在身体 → 未显化
- **应用** (8-9): 关系 / 幸福 / 不幸
- **收尾** (10): 臣服

## 核心轴线

- 思维 (80% 重复负面) → 小我 → 痛苦
- 临在 → 本体 → 喜悦
- 心理时间 → 焦虑 / 抑郁
- 当下 → 觉察 → 自由

## 关键洞察

- 痛苦的根源是**认同思维**
- 唯一真实的时间是**当下**
- 临在是**自由**的入口
- 臣服是**力量**的入口
