# 复习卡片

1. Q: 思维 8 要素?
   A: 目的 / 问题 / 信息 / 解释 / 概念 / 假设 / 意涵 / 观点

2. Q: 8 大认知美德?
   A: 谦逊 / 勇气 / 换位 / 一致 / 坚毅 / 信赖推理 / 思维自主 / 公正

3. Q: 思维 4 层级?
   A: 无反思 / 有反思 / 起点提升 / 行进提升

4. Q: 自我中心 vs 社会中心?
   A: 自我中心是个体默认机制, 社会中心是群体无意识

5. Q: 三大组织思维障碍?
   A: 隐蔽权力争斗 / 群体对现实的定义 / 官僚主义

6. Q: 11 大策略性思维观念?
   A: 思维-情绪-欲求相互依存 / 逻辑存在 / 定期评估 / 自我中心默认 / 敏感自我中心 / 大脑超出经验概括 / 自我中心看起来理性 / 自我中心自动 / 支配-服从权力 / 人类社会中心 / 理性需要努力
