# 时间

## 简介

**时间** 有两种:
- **钟表时间** (clock time) - 客观, 实用
- **心理时间** (psychological time) - 主观, 痛苦

## 关键命题

- 钟表时间 = 必要的 (约会, 计划)
- 心理时间 = 痛苦的 (焦虑过去, 担忧未来)
- 终结心理时间 = 回到**永恒的当下**
- 时间是**思维**创造的, 真实没有时间
