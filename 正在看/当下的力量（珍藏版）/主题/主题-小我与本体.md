# 主题: 小我与本体

## 核心命题

**小我** = 思维创造的虚假自我. **本体** = 你真实的自己. 觉醒 = 摆脱小我, 回归本体. 关系:**思维 → 小我 → 痛苦**, **临在 → 本体 → 喜悦**.
