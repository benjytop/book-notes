# 开悟 (Enlightenment)

## 简介

**开悟** 是本书的**最高目标**. 不是" 完美的未来", 是**当下**的临在. 意识从思维中**解放**.

## 关键命题

- 开悟 = 超越思维, 回归本体
- 开悟 = 摆脱**心理时间**
- 开悟 = 不被小我控制
- 开悟 = 简单 (但不容易)
