# 心理时间

## 简介

**心理时间** 是思维创造的**假时间** (过去 + 未来). 第 3 章核心. 与**钟表时间** (客观) 相对. 心理时间是痛苦的根源.

## 关键命题

- 心理时间 = 思维" 跳到" 过去或未来
- 心理时间 = **不活在当下**
- 心理时间造成**焦虑 + 抑郁**
- 终结心理时间 = 活在当下
