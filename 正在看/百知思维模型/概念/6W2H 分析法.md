# 6W2H 分析法

## 简介

**6W2H** 是结构化问题分析:
- **6W**: What / Why / Who / When / Where / Which
- **2H**: How / How much

## 关键命题

- 8 维度问问题
- 避免遗漏
- 适合复杂问题
- 5W1H 的扩展

## 应用

- 问题分析
- 决策
- 写作
