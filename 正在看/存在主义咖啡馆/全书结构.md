# 全书结构

## 三幕剧结构

- **第 1 幕 (1-3)**: 现象学传入法国, 起点
- **第 2 幕 (4-9)**: 存在主义**核心人物**登场 (萨特, 波伏娃, 海德格尔)
- **第 3 幕 (10-14)**: 存在主义的**扩展** (梅洛, 加缪, 列维纳斯) + **遗产**

## 核心轴线

- 哲学线: 现象学 → 存在主义 → 他者伦理
- 人物线: 胡塞尔 → 海德格尔 / 萨特 → 梅洛 / 加缪 / 列维纳斯
- 政治线: 二战 → 抵抗 → 战后的分化与决裂
- 爱情线: 萨特-波伏娃 终身伴侣

## 关键场景

- 1933 巴黎蒙帕纳斯煤气灯酒吧
- 1943 《存在与虚无》出版
- 1957 加缪获诺贝尔奖
- 1964 萨特拒诺贝尔奖
