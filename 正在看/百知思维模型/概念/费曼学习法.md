# 费曼学习法

## 简介

**费曼学习法** 是物理学家理查德·费曼的方法. 4 步:
1. 选择概念
2. 假装教给别人
3. 如果卡住, 回去重学
4. 简化语言

## 关键命题

- **教** 是最好的学
- 简单 = 真懂
- 卡住 = 漏洞
- 重学直到能教
