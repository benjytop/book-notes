# 荒诞

## 简介

**荒诞** 是存在主义的另一面. 加缪系统阐述. 人生无意义, 但仍要面对.

## 核心命题

- 荒诞 = 人的呼唤与世界沉默的冲突
- 荒诞感是**正常**的
- 面对荒诞的三个出路: 自杀 / 信仰 / **反抗**
- 西西弗斯神话: 推石头上山
