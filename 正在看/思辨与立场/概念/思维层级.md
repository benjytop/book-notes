# 批判性思维发展的四个层级

## 简介

批判性思维发展分**四个层级**, 个人在不同层级表现出不同的反思能力.

## 四个层级

1. **层级一**: 无思维反思意识者
2. **层级二**: 有思维反思意识者
3. **层级三**: 起点上的思维提升者
4. **层级四**: 行进中的思维提升者
