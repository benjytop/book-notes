# 本真性

## 简介

**本真性** (Authenticity / Eigentlichkeit) 是海德格尔和萨特的核心概念. 与" 非本真" (常人) 相对.

## 核心命题

- 海德格尔: 与**本己** (eigentlich) 相对
- 萨特: **自欺** (bad faith) 是非本真
- 本真 = 直面自己的自由
- 非本真 = 逃避, 随大流
