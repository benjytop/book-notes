# 首因效应与近因效应

## 简介

**首因效应** (Primacy Effect): 最先的信息记忆最牢. **近因效应** (Recency Effect): 最近的信息记忆最牢. **一头一尾, 都很深刻**.

## 关键命题

- 演讲 / 面试: 开场 + 结尾最重要
- 学习: 开始 + 复习最关键
- 一头一尾都做好, 中间可以放松
