# 黄金圈法则

## 简介

**黄金圈法则** 是西蒙·斯涅克提出. 三个圈: **Why** (为什么) / **How** (怎么做) / **What** (做什么). 大多数人从外往内 (What → Why), 伟大的领导者从内往外 (Why → How → What).

## 关键命题

- Why = 信念, 目的
- How = 价值观, 行动
- What = 成果
- 苹果 / 马丁·路德·金 都用这个

## 应用

- 演讲
- 营销
- 创业
- 个人品牌
