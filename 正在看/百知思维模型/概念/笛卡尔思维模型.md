# 笛卡尔思维模型

## 简介

**笛卡尔思维模型**: 用坐标系 (x, y, z) 思维. 把问题分解为多维度, 每一维独立考虑. **笛卡尔坐标系** 的思维方法.

## 关键命题

- 多维度 = 多视角
- 复杂问题 = 多维交叉
- 决策 = 找最优点
- 评估 = 各维加权

## 应用

- 决策 (多维度评估)
- 分析 (跨维度)
- 学习 (跨学科)
